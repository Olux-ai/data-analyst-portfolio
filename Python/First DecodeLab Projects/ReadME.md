\# Python To-Do List Application



\## About the Project



This is my \*\*first Python project at DecodesLabs\*\*.



I built this command-line To-Do List application to practice Python fundamentals, data structures, functions, user input, and file handling.



The application allows users to add, view, complete, and remove tasks. Tasks are saved in a JSON file so they remain available when the program is reopened.



\## Features



\* Add new tasks

\* View all tasks

\* Mark tasks as completed

\* Remove tasks

\* Validate user input

\* Save and load tasks using JSON

\* Use a simple menu-driven interface



\## Technologies Used



\* Python

\* JSON

\* Lists and dictionaries

\* Functions

\* Loops and conditional statements

\* File handling

\* Exception handling
